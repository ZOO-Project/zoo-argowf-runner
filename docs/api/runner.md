## Inherited from BaseRunner

Most of the runner's interface — `get_max_cores()`, `get_max_ram()`, `get_volume_size()`, `get_workflow_id()`, `assert_parameters()`, `update_status()` — is inherited unchanged from `BaseRunner`. See the [BaseRunner API reference](https://zoo-project.github.io/zoo-runner-common/api/base-runner/).
